SEM/TEM PARTICLE ANALYSIS - QUICK START (WINDOWS)
-------------------------------------------------

1) INSTALL PYTHON, CREATE THE ENVIRONMENT, AND INSTALL DEPENDENCIES
OPTION A - DOWNLOAD AND EXTRACT THE DISTRIBUTION ZIP
    Install Python 3.13 or 3.14 and select Add Python to PATH
    Extract the ZIP to a writable folder
    Open that folder, type "cmd" in the address bar, and run:

        py -3 -m venv .venv
        .venv\Scripts\activate
        python -m pip install --upgrade pip
        python -m pip install -r requirements.txt

OPTION B - INSTALL FROM GITHUB (RECOMMENDED FOR UPDATES)
    git clone https://github.com/VitPavelka/sem_coverage.git
    cd sem_coverage
    py -3 -m venv .venv
    .venv\Scripts\activate
    python -m pip install --upgrade pip
    python -m pip install -r requirements.txt

2) ACTIVATE THE ENVIRONMENT BEFORE EACH USE
    .venv\Scripts\activate

3) CHOOSE THE CONFIG AND PATHS
    Use forward slashes in JSON where practical, for example:

        "folder": "C:/Data/SEM/sample_01"

    A single unescaped backslash is not valid JSON.
    Use CLI overrides instead of editing long paths when convenient:

        python run_bead_viewer.py --help
        python run_sem_coverage_viewer.py --help
        python run_tem_particle_viewer.py --help

4) TUNE WITH THE DIAGNOSTIC VIEWER FIRST
    python run_diagnostic_viewer.py --mode beads --config sem_bead_viewer_config.json
    python run_diagnostic_viewer.py --mode coverage --config sem_coverage_viewer_config.json

    Sliders commit on mouse release.
    Apply changes commits the current pending values explicitly.
    The title and status area show PENDING, RUNNING, or UP TO DATE.
    Coverage mode also disables conditionally inactive controls in place and
    explains why they are inactive.
    Beads and coverage are currently implemented. TEM diagnostics are planned.

5) VERIFY THE TUNED SETTINGS IN THE REGULAR VIEWERS
    python run_bead_viewer.py
    python run_bead_viewer.py --config sem_bead_viewer_config.json

    python run_sem_coverage_viewer.py
    python run_sem_coverage_viewer.py --config sem_coverage_viewer_config.json --folder "C:/Data/SEM coverage"

    python run_tem_particle_viewer.py
    python run_tem_particle_viewer.py --config tem_particle_viewer_config.json --file "TEM SeNPs 1.png"

    CLI overrides do not modify the source JSON config.
    Regular viewers may optionally create summary JSON files when configured,
    but final CSV/XLSX tables belong to the batch/export layer.

6) RUN BATCH EXPORTS FOR FINAL OUTPUTS
    python batch_export_protocols.py --bead-root "C:/Data/SEM beads" --outputs-dir outputs --table-format both
    python batch_export_protocols.py --bead-config sem_bead_viewer_config.json --outputs-dir outputs
    python batch_export_protocols.py --coverage-config sem_coverage_viewer_config.json --outputs-dir outputs
    python batch_export_protocols.py --batch-config batch_export_protocols.example.json --outputs-dir outputs
    python batch_export_tem_protocols.py --root "C:/Data/TEM" --outputs-dir outputs_tem --table-format xlsx
    python export_output_summaries.py --outputs-dir outputs --table-format both

    Bead batch export also writes a one-column *_values.txt file beside every
    bead histogram. It contains exactly the valid sizes selected by
    size_distribution_metric (mean X/Y diameter by default), for example:
    outputs/bead_histograms/sample_01_bead_mean_xy_diameter_um_values.txt

    --table-format csv   keeps the current CSV behavior
    --table-format xlsx  writes only Excel workbooks
    --table-format both  writes both CSV and XLSX
    --table-format none  writes no summary tables

    Coverage defaults to --coverage-branches configured. Each coverage config's
    ag_enable_secondary_coverage value chooses one-layer or two-layer analysis,
    and outputs are written directly below outputs. Explicit one-layer,
    two-layers, or both modes use separate coverage branch directories.

7) OPTIONAL: EXTRACT COMPACT PUBLICATION TABLES
    python extract_output_tables.py outputs
    python extract_output_tables.py outputs --dry-run
    python extract_output_tables.py outputs --drop-medians

    This recursively writes sibling CSV/XLSX files ending in -extracted.
    Defaults are coverage metric caps and homogeneity-domain region homo.
    Use --coverage-metric and --region to change those existing families.
    Source tables are untouched and values are only selected, never recalculated.
    Previous -extracted files are ignored. Existing outputs require --overwrite.
    --drop-medians is optional and removes only redundant descriptive medians;
    robust rotation estimators remain in the compact scientific columns.

8) UPDATE THE REPOSITORY SAFELY
    git status -sb
    git fetch origin
    git pull --ff-only
    python -m pip install -r requirements.txt --upgrade

    Back up locally edited *_config.json files before pulling updates.
    Full parameter reference and troubleshooting are in README.md.
