SEM/TEM PARTICLE ANALYSIS - QUICK START (WINDOWS)
-------------------------------------------------

OPTION A - DOWNLOAD AND EXTRACT THE DISTRIBUTION .zip file
1) Install Python 3.13 or 3.14 and select Add Python to PATH
2) Extract the entire ZIP to a folder of your choice
3) Open the folder, write "cmd" in the address bar and press enter
4) Run:

    py -3 -m venv .venv
    .venv\Scripts\activate
    python -m pip install --upgrade pip
    python -m pip install -r requirements.txt

OPTION B - INSTALL FROM GITHUB (RECOMMENDED FOR UPDATES)
1) Install Python 3.13 or 3.14 (select Add Python to PATH) and Git for Windows
2) Run in the folder you want to install the software:

    git clone https://github.com/VitPavelka/sem_coverage.git
    cd sem_coverage
    py -3 -m venv .venv
    .venv\Scripts\activate
    python -m pip install --upgrade pip
    python -m pip install -r requirements.txt

BEFORE EACH USE
    .venv\Scripts\activate

EDIT THE APPROPRIATE JSON CONFIG
Use forward slashes in Windows paths, fe:
    "folder": "C:/Data/SEM/sample"

RUN A VIEWER
    python run_bead_viewer.py
    python run_sem_coverage_viewer.py
    python run_tem_particle_viewer.py

TUNE SEM PARAMETERS INTERACTIVELY
    python run_diagnostic_viewer.py --mode beads --config sem_bead_viewer_config.json
    python run_diagnostic_viewer.py --mode coverage --config sem_coverage_viewer_config.json

Changes remain temporary until Save tuned config (or S) writes a tuned copy.
Sliders commit on mouse release, and Apply changes commits the current pending
values explicitly. The diagnostic title/status shows PENDING, RUNNING, or
UP TO DATE. Left/right changes images, up/down changes diagnostic stages, R
resets one parameter group, Shift+R resets all parameters, and H displays
keyboard help.
Beads mode uses independent dimension-line and measurement-label overlays.
Coverage mode adds ROI navigation with [ and ] for previous/next ROI and
\ for All ROIs, plus independent diameter-line and diameter-label overlays.
Coverage also disables conditionally inactive controls in place, explains why
they are inactive, uses the multi-radius list instead of the single coverage
radius when the list is populated, and updates global sphere filters plus
display contrast without rerunning full segmentation.
Beads and coverage are currently implemented. TEM diagnostics are planned.

CHECK AND INSTALL UPDATES
    git status -sb
    git fetch origin
    git pull
    python -m pip install -r requirements.txt --upgrade

Back up locally edited *_config.json files before pulling updates.
Left/right arrows change images. The sem coverage viewer also uses up/down arrows for diagnostic layers.
Full parameter reference and troubleshooting in the README.md file.
